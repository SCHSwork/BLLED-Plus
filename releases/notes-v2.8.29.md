## Crash reports
If the controller crashes or freezes, the next start now writes a **[Crash]** entry to the Activity log on the status page. The entry shows where the crash happened. If you see one, copy those lines and post them on Discord or GitHub so it can be tracked down.

## Fewer printer connection problems after restarts
Saving settings, installing an update, or tapping **Restart** now closes the printer connection properly before the controller restarts. Some printers refused new connections for a while when the old one was left open, which could leave the controller unable to reconnect after a restart.

## How to update
On 2.8.25 or newer: open the update page and tap **Install 2.8.29** in the **Update from GitHub** card.
By hand: use **BLLC_V2.8.29-lite.bin.ota** if you're not sure which layout you have.
