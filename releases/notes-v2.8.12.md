## Fixed
- The **Update from GitHub** card no longer spins forever if a check gets stuck: after a minute it says so and offers the file to download instead.
- Updates from GitHub now write each step to the **Activity** log, so a problem shows where it happened.

## How to update
On 2.8.6 or newer: open the update page and tap **Install 2.8.12** in the **Update from GitHub** card.
On older versions: download **BLLC_V2.8.12.bin.ota** below and upload it on the update page.
