## Signed updates
Every BLLED Plus release is now signed, and from this version on the controller only installs updates from GitHub that carry a valid BLLED Plus signature. A file that was swapped, changed or uploaded by someone else gets refused, even if it's on the releases page.

Uploading a file yourself on the update page still works the same, since that already needs your login.

## How to update
On 2.8.6 or newer: open the update page and tap **Install 2.8.11** in the **Update from GitHub** card.
On older versions: download **BLLC_V2.8.11.bin.ota** below and upload it on the update page.
