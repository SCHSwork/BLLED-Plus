## Fits the original BLLED layout again
Versions 2.8.5–2.8.18 were slightly too big for controllers still on the original BLLED storage layout, so installing them failed with "Not Enough Space". This version is smaller again (it keeps a shorter list of the security certificates used to check updates come from GitHub), so it installs on every controller, and one-tap updates from GitHub work on the original layout too. Releases are now checked to stay small enough.

## How to update
On 2.8.15 or newer: open the update page and tap **Install 2.8.19** in the **Update from GitHub** card.
On anything older, including the original BLLED firmware: download **BLLC_V2.8.19.bin.ota** below and choose it on the update page.
